# Эмулятор оболочки ОС

Учебный проект по разработке эмулятора командной строки UNIX-подобной ОС на Python с графическим интерфейсом (GUI).

## 1. Общее описание
Эмулятор имитирует работу командной строки. Программа имеет графический интерфейс (GUI) и поддерживает работу с виртуальной файловой системой (VFS), которая хранится в оперативной памяти. Это позволяет безопасно выполнять команды, не изменяя реальные файлы на компьютере.

## 2. Описание всех функций и настроек
Эмулятор поддерживает следующие аргументы командной строки при запуске:
- `--vfs` : Путь к физической директории, которая загружается в виртуальную файловую систему (VFS).
- `--log` : Путь к файлу лога в формате JSON. Туда записываются все команды и ошибки с указанием времени.
- `--script` : Путь к стартовому скрипту. Если указан, эмулятор автоматически выполнит команды из этого файла при запуске (и остановится при первой ошибке).

## 3. Описание команд для сборки проекта и запуска тестов
Проект не требует сторонних библиотек, кроме стандартной библиотеки Python (Tkinter).
Для запуска эмулятора в Windows используется файл `run.bat`.
Также запуск можно осуществить вручную через терминал:
python src/main.py --vfs "./vfs_data" --log "./log.json" --script "./test_vfs.txt"

## 4. Примеры использования
После запуска в окне эмулятора доступны следующие команды:
- `ls` — вывести список файлов и папок в текущей директории.
- `cd <папка>` — перейти в указанную папку (или `cd ..` для возврата назад).
- `cat <файл>` — вывести содержимое текстового файла на экран.
- `mkdir <папка>` — создать новую папку.
- `touch <файл>` — создать новый пустой файл.
- `exit` — закрыть эмулятор.
