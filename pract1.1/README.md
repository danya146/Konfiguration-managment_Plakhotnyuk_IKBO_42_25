# Эмулятор оболочки ОС (Вариант 23)



## Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом (GUI). Этап 1: минимальный прототип (REPL).



## Функции и настройки

- GUI-интерфейс на базе `tkinter`.

- Заголовок окна: `Эмулятор - \[username@hostname]`.

- Парсер аргументов с поддержкой кавычек.

- Команды-заглушки: `ls`, `cd`.

- Команда выхода: `exit`.



## Команды для сборки и запуска

- Запуск: `make run` или `python -m src.main`

- Тесты: `make test` или `python -m unittest discover tests`



## Примеры использования

Ввод: `ls -la "Моя папка"`  

Вывод: `ls: аргументы: \['-la', 'Моя папка']`



Ввод: `cd /home/user`  

Вывод: `cd: аргументы: \['/home/user']`
