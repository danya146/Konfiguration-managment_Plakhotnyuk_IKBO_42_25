# Инструмент визуализации графа зависимостей (Вариант 23)

## 1. Общее описание
Данный проект представляет собой CLI-инструмент (Command Line Interface) для анализа и визуализации графа зависимостей пакетов Python (менеджер пакетов `pip`). 
Инструмент позволяет получать информацию о прямых и транзитивных зависимостях заданного пакета, строить граф зависимостей с помощью алгоритма поиска в глубину (DFS), обрабатывать циклические зависимости, вычислять порядок загрузки пакетов (топологическая сортировка) и визуализировать результат в виде ASCII-дерева или диаграммы PlantUML.

## 2. Описание всех функций и настроек
Приложение поддерживает следующие параметры командной строки:
* `--package`, `-p` (обязательный) — Имя анализируемого пакета (например, `requests`).
* `--repo` — URL-адрес репозитория или путь к локальному файлу тестового репозитория.
* `--test-mode` — Флаг включения режима работы с тестовым репозиторием (чтение локального файла).
* `--version`, `-v` — Версия анализируемого пакета (по умолчанию: `latest`).
* `--ascii-tree` — Флаг вывода зависимостей в формате ASCII-дерева.
* `--plantuml` — Флаг вывода графа в формате PlantUML.
* `--depth`, `-d` — Максимальная глубина анализа зависимостей (целое число > 0, по умолчанию: `3`).
* `--filter` — Подстрока для фильтрации пакетов (исключает пакеты, содержащие эту подстроку).
* `--load-order` — Флаг вывода порядка загрузки зависимостей (топологическая сортировка).

## 3. Описание команд для сборки проекта и запуска тестов
Проект не требует компиляции (интерпретируемый язык Python). Все зависимости являются стандартными библиотеками Python.

**Запуск приложения:**
* Windows: `run.bat [параметры]`
* Linux/Mac: `./run.sh [параметры]`
* Через Makefile: `make run [параметры]`

**Запуск тестов:**
* Через Makefile: `make test`
* Напрямую через Python: `python -m unittest discover -s tests -v`
