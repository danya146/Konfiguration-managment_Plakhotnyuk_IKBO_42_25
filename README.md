\# Инструмент визуализации графа зависимостей



\## 1. Общее описание

Программа представляет собой CLI-инструмент для анализа и визуализации графа зависимостей пакетов Python (менеджер пакетов `pip`). 

Инструмент позволяет получать информацию о прямых и транзитивных зависимостях заданного пакета, а также визуализировать их в виде текста или ASCII-дерева.



\## 2. Описание всех функций и настроек

Приложение поддерживает следующие параметры командной строки:



\* `--package`, `-p` (обязательный) — Имя анализируемого пакета (например, `requests`).

\* `--repo` — URL-адрес репозитория или путь к локальному файлу тестового репозитория.

\* `--test-mode` — Флаг включения режима работы с тестовым репозиторием (локальный файл).

\* `--version`, `-v` — Версия анализируемого пакета (по умолчанию: `latest`).

\* `--ascii-tree` — Флаг вывода зависимостей в формате ASCII-дерева.

\* `--depth`, `-d` — Максимальная глубина анализа зависимостей (целое число > 0, по умолчанию: `3`).

\* `--filter` — Подстрока для фильтрации пакетов.



\## 3. Описание команд для сборки проекта и запуска тестов

Проект не требует сборки (интерпретируемый язык Python). 

Для запуска используйте скрипты:

\* Windows: `run.bat \[параметры]`

\* Linux/Mac: `./run.sh \[параметры]`

\* Через Makefile: `make run`



Запуск тестов (будет реализовано на следующих этапах):

\* `make test` или `pytest tests/`
