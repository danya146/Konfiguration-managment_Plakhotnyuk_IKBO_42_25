# Инструмент визуализации графа зависимостей



## Общее описание

Инструмент для визуализации графа зависимостей менеджера пакетов на Python.

Реализованы все 5 этапов практики.



## Функции и настройки

 `--package` / `-p`: Имя пакета (обязательно)

 `--repo` / `-r`: URL или путь к файлу (обязательно)

 `--version` / `-v`: Версия пакета (обязательно)

 `--test-mode` / `-t`: Тестовый режим (флаг)

 `--ascii-tree` / `-a`: ASCII-дерево (флаг)

 `--depth` / `-d`: Глубина анализа (по умолчанию 3)

 `--filter` / `-f`: Подстрока фильтрации
